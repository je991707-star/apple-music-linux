# Main-owned typed source qualification

This harness imports the normal Electron Main/preload and bundles the entire
production Controller. The only private Renderer changes provide a fixed local
queue/audio element, omit the DRM capability wait for clear generated bytes,
and export diagnostic actions. `build-controller.mjs` verifies critical playback
functions remain byte-identical. It does not extract an alternative Controller,
change MusicKit authorization, or provide an account principal.

The actual Main mints its random principal and issuer. Its in-process source
adapter must explicitly approve an immutable fixture; no IPC can approve one.
The real Engine factory opens a Private PlaybackManager Session and reserves
its real lifetime Lease. Native commands still use the existing Gate/Ticket/
Player final-entry fence. `u2_source_fixture,vlc_ordering_test` supplies only
pinned, account-free data and a PCM observation sink. Default builds exclude it.

Normal release builds deliberately have **no qualified account source factory**.
The normal Main cannot turn a Renderer asset ID, URL, file, token or guessed
Session into source authority. No real account/DRM integration is qualified here.

Run from the U2 worktree with a fresh `.u2-lab/u2-5-*` directory. Never reuse a
staged profile/results directory. The delivery Lab's `REPRODUCE.md` gives exact
compiler/environment/fixture paths and commands. `U2_SOURCE_LAB` selects a new
Lab for staging; `U2_LAB` selects its private Go caches. `build-controller.mjs`
takes that Lab as its first argument. Source Engine artifact name is currently
`engine-source-no-drm-v8`; use that output name when reproducing.

`extract-handlers.py` qualifies the existing recording Handler contracts only.
It stubs the new Main-only branches fail-closed; the actual Main authority tests
are `engine/cmd/main_source_fixture_test.go` with the real Manager/libVLC. Never
claim the recording test proves source authorization or PCM output.

`release-inspect.mjs LAB SUFFIX` creates a production-code ASAR from an ordinary
bundle (without the private queue), and inspects a default untagged Engine. This
is NOT a full installer/native-DRM build or production login qualification.
